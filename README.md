# JustSink

**A simple sink block mod for Minecraft**

<img src="https://img.shields.io/badge/Minecraft-1.21.1-green?style=flat-square" alt="Minecraft 1.21.1">
<img src="https://img.shields.io/badge/NeoForge-21.1.230-blue?style=flat-square" alt="NeoForge">

## 📜功能

- 一个水槽方块
- 无限水源 / 垃圾桶

## 📦 依赖

| 依赖 | 版本 | 类型 |
| --- | --- | --- |
| Minecraft | 1.21.1 | 必需 |
| NeoForge | 21.1.230+ | 必需 |
